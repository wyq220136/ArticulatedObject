# Windows 本地运行指南

本目录提供 Windows 环境下的 SceneEditor 启动入口。资产扫描、manifest
格式和场景状态仍然复用上一级目录的通用实现；Windows 专用内容只放在本
目录中。

## 1. 准备 Python 环境

建议使用已经安装 SAPIEN 的 Python 或 conda 环境。在 PowerShell 中确认：

```powershell
python --version
python -c "import yaml, trimesh; print('基础依赖正常')"
```

安装交互界面依赖：

```powershell
python -m pip install viser
```

如果系统中有多个 Python，可以通过环境变量指定解释器：

```powershell
$env:PYTHON_BIN = "D:\term_files\anaconda\envs\sapien\python.exe"
```

## 2. 配置模型白名单

默认读取：

```text
DatasetGenerator/SceneEditor/config.yml
```

也可以复制 `config.example.yml`，修改其中的 `models_root` 后作为独立配置
文件传入。`models` 是启动时加载的模型白名单，路径相对于 `models_root`：

```yaml
models_root: D:/research/sapien/Models
manifest_output_dir: ./scene_manifests
models:
  - bottle/3517
  - category: box
    instance: 1001
```

只会打开 `models` 中列出的目录，不会遍历整个 Models 文件夹。每个模型目录
需要包含 `mobility.urdf` 和 `mobility_v2.json`。列表为空时，界面不会显示可选
模型，也不会触发全目录扫描。

## 3. 启动界面

在仓库根目录执行：

```powershell
.\DatasetGenerator\SceneEditor\windows\run.ps1
```

如果 PowerShell 禁止执行本地脚本，可以只对当前进程放宽策略：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\DatasetGenerator\SceneEditor\windows\run.ps1
```

指定配置文件：

```powershell
.\DatasetGenerator\SceneEditor\windows\run.ps1 `
  .\DatasetGenerator\SceneEditor\windows\config.example.yml
```

也可以绕过 PowerShell 脚本直接运行：

```powershell
python DatasetGenerator/SceneEditor/windows/run.py `
  DatasetGenerator/SceneEditor/config.yml
```

启动后终端会打印 Viser 地址，通常为 `http://127.0.0.1:8080`，在浏览器中
打开即可。

## 4. 编辑和保存 manifest

界面支持：

- 显示与数据生成链路一致的桌面和桌腿；
- 从白名单中选择模型并添加到场景；
- 删除选中的物体；
- 编辑物体的 XYZ 位置；
- 编辑 Roll/Pitch/Yaw 三轴旋转角；
- 编辑统一 `scale` 缩放值，三个方向等比例缩放；
- 选中物体后同时显示平移和旋转两个 3D transform gizmo，用鼠标拖动平移或旋转；
- 选中物体后可在 `movable_part` 列表选择盒盖、抽屉、门等可动 part；交互会遵守
  URDF 的关节轴和限位，不能自由脱离关节约束；
- 设置场景名称并保存 manifest。

在 `Objects` 面板中选择物体后，场景中会同时出现平移箭头和旋转环，不再需要
切换操作模式。选择 `movable_part` 后，两个控件会跟随该 part；revolute/continuous
关节只响应绕关节轴的旋转，prismatic 关节只响应沿关节轴的平移。控件尺寸会随
当前物体或 part 的 mesh 尺寸变化。数值输入和鼠标操作都会同步到完整的 9D 参数、
articulation qpos 及 part pose，并随保存按钮写入 manifest。

保存文件位于 `manifest_output_dir`，格式与 Linux 入口生成的 manifest 一致，
可以直接交给 `DatasetGenerator/run.py --manifest` 使用。

## 5. 常见问题

- 报 `viser is required`：在实际执行 `run.py` 的同一个 Python 环境中安装
  `viser`。
- 报模型目录不存在：检查 `models_root`、类别/实例名称及相对路径。
- 启动很慢：减少 `models` 白名单条目；不要把整个 Models 根目录写进列表。
- 端口占用：在 YAML 中修改 `port`，然后重新启动。

当前 Windows 入口不会自动启动 SAPIEN 渲染任务，也不会生成数据集帧；它负责
交互式配置并保存 manifest，后续数据生成仍由 DatasetGenerator 完成。
